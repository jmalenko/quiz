# Project Assessment and Control

> **IEEE/IEC 12207:2017 — Technical Management Process 6.3.2**

## Purpose
Assess project progress and performance against plans, and control execution to correct deviations.

## Key Activities
- Monitor project progress against plan
- Assess achievement of objectives
- Identify deviations and issues
- Take corrective/preventive action
- Report project status

## Outputs (AI Generates)
- `STATUS_REPORT.md` — Project status template
- `DEVIATION_LOG.md` — Tracking deviations from plan
- `CORRECTIVE_ACTIONS.md` — Actions taken to address issues
