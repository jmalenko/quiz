# Configuration Management

> **IEEE/IEC 12207:2017 — Technical Management Process 6.3.5**

## Purpose
Manage and control system elements and configurations, maintaining integrity and traceability.

## Key Activities
- Identify configuration items (CIs)
- Establish configuration baselines
- Control changes to CIs
- Record and report configuration status
- Verify configuration completeness and consistency

## Outputs (AI Generates)
- `CONFIGURATION_PLAN.md` — CM approach and procedures
- `CONFIGURATION_ITEMS.md` — CI register (what is under CM)
- `BASELINE_REGISTER.md` — List of established baselines
- `CHANGE_CONTROL.md` — Change control process
