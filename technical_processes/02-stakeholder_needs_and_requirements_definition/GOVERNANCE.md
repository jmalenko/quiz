# Governance — Stakeholder Needs and Requirements Definition

## Methodology

Stakeholder needs are captured as **User Stories** with **BDD acceptance criteria**.

## High Level Format

```
As a [stakeholder],
I want [capability],
so that [benefit].
```

## Detailed Format

Each story is expanded with acceptance criteria:

```
Given [precondition],
When [action],
Then [expected result].
```

## Prioritization

Everything defined is required. If it's not needed, don't include it.
