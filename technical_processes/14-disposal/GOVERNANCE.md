# Governance — Disposal

## Methodology

### ISO/IEC/IEEE 12207:2017 — Disposal process (clause 6.4.14)

Defines Disposal as the process that retires the system from operation and removes it from its environment. It requires notifying affected parties, archiving or destroying system artefacts and data per applicable policy, and confirming the system is no longer operational.

### Data protection

If the system processes personal data, disposal must include secure deletion per applicable regulation (e.g. GDPR). This project (a stateless quiz app with no user accounts or personal data) has no such obligation.

---

## High Level Format

Human provides key disposal instructions — the decision, its rationale, and any specific constraints on how the system should be retired.

---

## Detailed Format

AI expands into a **Disposal Procedure** covering all steps to safely stop, remove, and archive the system.

---

## Artifacts Format

AI executes the Disposal Procedure.

AI generates a **Disposal Report** — a confirmation document recording the completion of each step in the Disposal Procedure (from the Detailed layer), with evidence (command output, timestamps, URLs).
