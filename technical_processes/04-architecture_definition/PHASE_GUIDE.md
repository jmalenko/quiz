# Architecture Definition

> **IEEE/IEC 12207:2017 — Technical Process 6.4.4**

## Purpose
Generate system architecture alternatives, select one, and express it through architectural views.

## Key Activities
- Define architecture viewpoints and views
- Develop candidate architectures
- Assess candidates (trade-off analysis)
- Select architecture and document rationale
- Allocate requirements to architectural elements

## Inputs
- `../03-system_software_requirements_definition/SYSTEM_REQUIREMENTS.md`
- `USER_INPUT.md` — Technology preferences

## Outputs (AI Generates)
- `ARCHITECTURE.md` — Architecture description (multiple views)
- `COMPONENT_CATALOG.md` — Components and responsibilities
- `INTERFACE_DEFINITIONS.md` — Inter-component interfaces
- `ARCHITECTURE_DECISIONS.md` — ADRs with rationale
- `DEPLOYMENT_VIEW.md` — Physical deployment topology
- `TRACEABILITY.md` — Architecture → Requirements allocation
